# 🌿 IRL Quest — Touch Grass, Level Up!

**IRL Quest** is a gamified real-life mission app that encourages you to step away from the screen, explore the real world, and complete small challenges to earn XP and unlock achievements.

Built for the **“Touch Grass”** theme, IRL Quest turns everyday activities into quests!

## ✨ Features

- 🎯 **Real-Life Missions** — Complete small, practical challenges in the real world.
- 🤖 **AI-Generated Missions** — Generate personalized missions using a locally running Ollama model.
- ⭐ **XP & Leveling System** — Earn XP as you complete missions and progress through ranks.
- 🏆 **Achievements** — Unlock achievements for your progress and activity.
- ⏱️ **Mission Timer** — Track the time you spend on a quest.
- 💾 **Local Progress Storage** — Save your progress in your browser using local storage.
- 🌱 **Touch Grass Philosophy** — Encourages offline activities, exploration, and healthier screen habits.

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- Ollama for local AI generation
- Qwen3 4B model
- Browser Local Storage

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project

Open the project folder in Visual Studio Code.

### 3. Start the app

Run `index.html` using the VS Code **Live Server** extension.

### 4. Enable AI mission generation

1. Install [Ollama](https://ollama.com/).
2. Download the model:

   ```bash
   ollama pull qwen3:4b
   ```

3. Make sure Ollama is running locally.
4. Open IRL Quest in your browser and try generating an AI mission.

**Note:** AI mission generation requires Ollama to be running locally and may take some time depending on your hardware. The rest of the app may work without AI, depending on its implementation.

## 🎮 How to Play

1. Open IRL Quest.
2. Choose a mission or generate one with AI.
3. Complete the real-world activity.
4. Track your mission progress.
5. Earn XP and unlock achievements.
6. Keep exploring and level up!
